# ZeroStep 광고/과금 수익화 전략 (KR/EN/JP 출시 기준)

## 1. 전제 (현재 게임 구조 기반)
- 장르: 스테이지형 퍼즐, 실패(Game Over) 빈도가 수익화 지점이 됨.
- 루프: `도전 -> 실패/클리어 -> 재도전` 반복.
- 현재 코드상 주요 이벤트 트래킹 존재: `stage_start`, `stage_fail`, `stage_clear`, `stage_skip`, `stage_reset`, `settings_popup_open`.
- 따라서 광고/과금은 **실패 후 회복(flow recovery)** 과 **진행 가속(flow acceleration)** 중심으로 설계하는 것이 가장 효율적.

## 2. 핵심 원칙 (수익 + 잔존율 동시 최적화)
1. 강제광고는 적게, 보상형 광고는 명확하게.
2. 하트 시스템은 "막는 장치"가 아니라 "선택지를 만드는 장치"로 운영.
3. 광고제거 구매자는 존중: 강제광고 제거, 보상형 광고는 선택 유지.
4. 광고 빈도는 정책 준수 + 피로도 제어.

참고(공식 정책/플랫폼):
- AdMob: 반복적 인터스티셜 과다 노출 금지(행동마다 노출 금지, 최소 2개 액션당 1회 이하 권장).  
  https://support.google.com/admob/answer/6201362?hl=en
- Apple IAP 가격: 국가별 자동 환율/세금 반영, 다수 price point 제공.  
  https://developer.apple.com/help/app-store-connect/manage-in-app-purchases/set-a-price-for-an-in-app-purchase
- Google Play 가격: 국가별 로컬 가격 자동 변환/수동 조정 가능.  
  https://support.google.com/googleplay/android-developer/answer/138412?hl=en

## 3. 하트 시스템 권장안

### 3.1 기본 룰
- 최대 하트: `3`
- 실패 시: `-1`
- 하트 0 시: 스테이지 진입 제한
- UI: ProgressBar 아래 3칸 고정
  - 보유: `heart.png`
  - 소진: `heart_empty.png`

### 3.2 회복 경로 (중요)
하트 0 팝업 버튼은 3개 권장:
1. `기다리고 충전` (예: 20분당 +1)
2. `광고 보고 +1 하트`
3. `하트팩 구매` (일회성 상품)

추가:
- `광고 보고 전체 충전(하루 1회)` 버튼은 리텐션에 유리.
- 초기 유저 피로 완화용으로 Day1~Day2는 재생성 시간을 조금 짧게(예: 15~20분) 운영 후 정상화 가능.

## 4. 광고 배치 설계

### 4.1 보상형 광고 (주력 수익)
- 실패 직후 제안: `광고 시청 -> 하트 소모 없이 즉시 재도전`
- 하트 0 팝업: `광고 시청 -> +1 하트`
- 일일 보상: `광고 시청 -> 전체 하트 충전(1일 1회)`

권장 제한:
- 실패 직후 보상형 제안은 `스테이지당 최대 1회`.
- 보상형 연속 노출 쿨다운: `60~90초`.

### 4.2 인터스티셜 광고 (보조 수익)
- 노출 위치: `스테이지 클리어 후 다음 스테이지 진입 전`만 사용.
- 빈도 캡 예시:
  - `2회 클리어당 1회` 또는
  - `세션당 최대 3회` + `노출 간 최소 120초`.
- 절대 금지:
  - 앱 시작 직후
  - 게임오버 직후 연속 노출
  - UI 클릭마다 노출

### 4.3 배너 광고
- 퍼즐 플레이 화면에서는 비권장(집중력 저해).
- 사용한다면 메뉴/로비 화면에서만 적응형 배너로 제한.

## 5. 광고제거 + 일회성 상품 가격 제안

아래는 **출시 시작점** 권장값(스토어 로컬 가격 자동환산 기준):

### 5.1 광고제거 (Non-consumable)
- 상품명: `광고 제거`
- 기능: 인터스티셜/배너 제거, 보상형 광고는 유지(선택형)
- 권장가:
  - 테스트 A: `KRW 4,400` (약 USD 2.99 레벨)
  - 테스트 B: `KRW 6,600` (약 USD 4.99 레벨) <- 추천 기본

### 5.2 일회성(Consumable) 상품
1. `하트 +3`
- 권장가: `KRW 1,100` (약 USD 0.99)

2. `하트 +10`
- 권장가: `KRW 3,300` (약 USD 2.49)

3. `스킵 티켓 x3`
- 권장가: `KRW 2,200` (약 USD 1.99)

4. `스타터 팩 (초회 1회)`
- 구성: 하트 +15, 스킵 x5, 인터스티셜 24시간 제거
- 권장가: `KRW 5,900` (약 USD 3.99)

### 5.3 번들 앵커 전략
- 단품 대비 `20~35%` 이득 체감되도록 번들 구성을 잡아야 구매전환 상승.
- 스토어 노출 순서: `스타터팩 -> 광고제거 -> 하트팩`.

## 6. 수익 극대화 운영안 (필수)

### 6.1 AB 테스트 순서
1. 광고제거 가격: `4,400 vs 6,600`
2. 하트 재생성 시간: `20분 vs 30분`
3. 인터스티셜 빈도: `2클리어당 1회 vs 3클리어당 1회`
4. 실패 보상형 카피:
   - A: "광고 보고 즉시 재도전"
   - B: "하트 소모 없이 한 번 더"

### 6.2 KPI 목표선
- D1 Retention: `>= 35%`
- Rewarded opt-in: `>= 25%`
- Interstitial 이탈률 증가폭: `<= +3%p`
- 광고제거 구매율: `1~2%`
- 결제전환율(Payer conversion): `2~4%`
