■ JSON 스테이지 시스템 요약

1. StageData.cs
   - stageID, width, height, startPoint { x, y }, cells[] { x, y, count }
   - JsonUtility 직렬화용 [Serializable] 클래스

2. StageManager.cs
   - LoadStage(int stageNumber) → Resources/Stages/stage_{번호}.json 로드 후 StageData 반환

3. 샘플 JSON (Assets/Resources/Stages/)
   - stage_1.json: 3x3 전체, 숫자 1~3, 시작점 (0,0)
   - stage_2.json: 3x3, (1,1) 빈칸(count=0), 나머지 2, 시작점 (0,1)
   - stage_3.json: ㄴ자 모양, (0,0)(0,1)(0,2)(1,2)(2,2)만 타일, 시작점 (0,0)

4. GameManager
   - 시작 시 StageManager.LoadStage(1) → CreateGridFromStageData (count>0만 Instantiate)
   - 시작점 타일: SetAsStartPoint(true) → 테두리 틴트 + (선택) Start 텍스트
   - 모든 타일 0 → "Stage Clear" 로그 → nextStageDelay 후 다음 스테이지 로드
   - 다음 스테이지 없으면 "All stages clear. 처음 스테이지부터 다시." 후 1스테이지 재시작

5. Tile
   - SetAsStartPoint(bool): startLabel 표시(있을 때), 스프라이트 틴트로 시작점 구분
