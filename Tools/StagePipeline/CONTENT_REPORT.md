# ZeroStep level content without walls (1,000 stages)

This directory is the shipped 1,000-stage set (`../out`, identical to the stages currently in the project) with the **Wall mechanic removed completely**. No stage has a `walls` field any more and no candidate that uses walls was considered. All other rules and content requirements are unchanged (Charge stays). Every stage was re-verified with the exhaustive C solver while building and is re-verifiable with `python3 -I validate.py` (pure Python, independent solver + stroke replay + per-instance ablation; Wall dropped from its mechanic lists and any `walls` field is now a failure).

## Notes

* Rules are otherwise exactly those of the shipped set (TILE_RULES.md): TwinLink-group clear modelled as in GameManager.cs, every provided solution ends with the plain clear; no two Charge tiles adjacent and no FixedKnot/Igniter/Hidden next to a Charge.
* The game code and `Assets/rules/TILE_RULES.md` still describe walls; with this set no stage uses them (the validator fails on any `walls` field). Removing the wall code/docs is optional and was not part of this change (nothing inside the project was modified).
* Difficulty metrics are random-play statistics (p_random, crit_steps) as before. A board without its walls usually has more legal moves, which can make random play *less* likely to win, so -log10 p_random of a de-walled board is not systematically lower; each same-board reuse was accepted only within 0.35 of the old value.
